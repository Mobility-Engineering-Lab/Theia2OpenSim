# OpenSim sample output folder

This folder is reserved for OpenSim-ready example outputs produced by the script workflow.

Recommended contents:

- `.mot` motion files exported from `src/Python/run_pipeline.py`
- `.trc` static marker files (when script export is finalized)
- optional OpenSim setup files used for verification

No model files are committed yet; add project-specific OpenSim assets as needed.
